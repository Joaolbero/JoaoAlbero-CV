| --- | --- |

### 🔧 Comandos (exemplo com Python 3)

Clone do repositório:

    git clone https://github.com/Joaolbero/JoaoAlbero-CV.git
    cd JoaoAlbero-CV

Servir localmente:

    python -m http.server 8000
    # Acessar: http://localhost:8000
